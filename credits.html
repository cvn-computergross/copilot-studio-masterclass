Microsoft Agent Academy ​

Alcune parti delle guide dei lab sono adattate da Microsoft Agent Academy, il percorso gratuito di Microsoft per imparare a creare agenti con Copilot Studio. Il caso pratico dell'Advanced prende spunto dal percorso Operative, quello dell'Hiring Agent.
