# Copilot Studio Masterclass Labs

Hands-on labs for learning Microsoft Copilot Studio through a single, GitHub-friendly sequence of Markdown guides.

## How To Use This Repository

Start with Lab 01 and continue in order. The first five labs establish the Copilot Studio foundations, then the sequence intentionally shifts into an end-to-end hiring scenario that applies those same concepts in a connected workflow.

Each lab lives in its own folder under [`labs/`](./labs/) and includes a local `README.md` plus any images or supporting files it needs.

## Prerequisites

- A work or school Microsoft 365 account
- Access to Copilot Studio
- Familiarity with Microsoft 365 basics
- SharePoint and Dataverse access for labs that require knowledge sources or structured data
- Frontier preview access only for Lab 12
