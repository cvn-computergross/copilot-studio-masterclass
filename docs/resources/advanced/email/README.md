# Email di prova

Questi testi servono per provare l'intake automatico via email (percorso standard: lab 05; percorso GitHub Copilot: lab 07, 08 e 09).

| File | Caso | Usato in |
| --- | --- | --- |
| `email-01-proposta-singola.txt` | Una proposta, un PDF | S05, G07, G09 |
| `email-02-risposta-automatica.txt` | Risposta automatica | S05, G07 |
| `email-03-newsletter.txt` | Messaggio promozionale | S05, G07 |
| `email-04-richiesta-ambigua.txt` | Domanda sul processo, nessuna proposta certa | S05, G09 |
| `email-05-due-proposte.txt` | Due business case, PDF e DOCX | S05 (facoltativo), G07 |
| `email-06-programma-contraddittorio.txt` | Programma diverso tra email e documento, testo di prompt injection | G08 |
| `email-07-programma-da-definire.txt` | Programma non univoco nel documento | G08 |

Come usarli:

1. Apri Outlook con un account del tuo tenant di laboratorio.
2. Crea un nuovo messaggio verso la casella monitorata dal trigger (di solito la tua).
3. Copia **Oggetto** e **Corpo** dal file di prova e allega i file indicati in **Allegati**, presi dalla cartella `materiali/business-case`.
4. Invia il messaggio solo quando il trigger è attivo (vedi le istruzioni del lab).

Tutti i nomi, gli indirizzi e gli importi sono fittizi. Non inviare questi messaggi a indirizzi esterni al tuo tenant.
