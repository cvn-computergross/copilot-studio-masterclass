## Fatti verificati che hanno guidato il progetto dei laboratori

- **Work IQ lavora sul tenant dell'utente.** In Copilot Studio va aggiunto come strumento unico **Work IQ (Preview)**; gli strumenti separati per carico di lavoro restano solo per prove e compatibilità. Work IQ è in sola lettura finché un amministratore non abilita le scritture nel Microsoft 365 admin center. Per questo la pianificazione coinvolge solo persone interne (G10) e il percorso standard usa i connettori Office 365.
- **Input documento dei prompt.** Nella standard harness i prompt accettano come documento PDF e immagini; per passare un file a un prompt dalla conversazione serve un agent flow con **Run a prompt** (S02, S03). Per questo BC-05 è fornito anche in PDF.
- **Moderazione.** Standard harness: livelli dell'agente da **Lowest** a **Highest** (predefinito **High**), livelli del prompt da **Low** a **High** (predefinito **Moderate**). GitHub Copilot harness: **Moderation level** da **Minimum** a **Maximum** (G04).
- **Identità dell'agente nella GitHub Copilot harness.** Schema name, soluzione e lingua principale diventano di sola lettura dopo il primo salvataggio (G01).
- **Dataverse MCP Server.** È abilitato per impostazione predefinita per Copilot Studio (impostazione **Allow MCP clients to interact with Dataverse MCP server**); gli strumenti si limitano disattivando **Allow all** e scegliendo i singoli strumenti (L00, G02, G03).
- **Agent node nei workflow.** Un agente inline può usare **Request human assistance**, che invia la richiesta per email al proprietario della connessione; un agente pubblicato si chiama con un **Message** (G08).
- **Monitor.** Nella standard harness la pagina di analisi si chiama ora **Monitor**; nella GitHub Copilot harness la scheda **Monitor** riunisce sessioni, reazioni e crediti; la funzione **User feedback** si attiva in **Settings**, **Safety & access** (S08, G11).
- **Condivisione nella GitHub Copilot harness.** Richiede autenticazione **Authenticate with Microsoft** e la pubblicazione in **Teams + Microsoft 365**; concede diritti di uso, non di modifica (G11).
