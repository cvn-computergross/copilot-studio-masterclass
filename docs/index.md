# Copilot Studio Masterclass

Hands-on labs for learning Microsoft Copilot Studio, organized into two learning paths.

Before starting, read [Info](./info.md). Files to download are in [Resources](./resources/index.md).

| Path | Description |
|------|-------------|
| [Standard Harness](./standard-harness/index.md) | Build agents in the Copilot Studio portal, from environment setup to multi-agent and autonomous scenarios. 13 labs. |
| [GitHub Harness](./github-harness/index.md) | Build and manage agents with a code-first, GitHub-based workflow. Work in progress. |
