# Fondamentali · Standard Harness

[← Home del corso](../../../README.md)

Nella Standard Harness gli agenti si creano direttamente nel portale di Microsoft Copilot Studio. Parti dal Lab 01 e prosegui in ordine: i cinque lab costruiscono le basi di Copilot Studio. Dopo i fondamentali, il percorso continua con il caso pratico della sezione Advanced.

## Prerequisiti <!-- icon: list-checks f-instructions -->

- Un account Microsoft 365 aziendale o scolastico
- Accesso a Copilot Studio
- Conoscenza di base di Microsoft 365
- Accesso a SharePoint e Dataverse per i lab che usano fonti di conoscenza o dati strutturati
